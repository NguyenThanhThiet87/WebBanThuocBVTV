# 🌱 Website Bán Thuốc Bảo Vệ Thực Vật

Dự án xây dựng hệ thống website bán thuốc bảo vệ thực vật, cung cấp giải pháp mua sắm trực tuyến, quản lý sản phẩm, đơn hàng và khách hàng, tích hợp AI nhận diện một số bệnh cây trồng phổ biến giúp người nông dân xác định được loại bệnh của cây. Hệ thống hướng đến người nông dân, chủ đại lý và người tiêu dùng có nhu cầu tiếp cận sản phẩm nhanh chóng, thuận tiện.

# 🚀 Công nghệ sử dụng
| Công nghệ                        | Mô tả                                                    |
|----------------------------------|----------------------------------------------------------|
| ASP.NET MVC                      | Xây dựng backend & xử lý nghiệp vụ                      |
| SQL Server                       | Hệ quản trị cơ sở dữ liệu                               |
| HTML, CSS, Bootstrap             | Xây dựng giao diện frontend                             |
| Entity Framework                 | ORM thao tác với cơ sở dữ liệu                          |
| Visual Studio                    | Môi trường phát triển dự án                             |
| Python                           | Xử lý AI & huấn luyện mô hình nhận diện bệnh cây        |
| MobileViTv2                      | Mô hình nhận diện hình ảnh bệnh cây trồng               |
| ONNX                             | Triển khai mô hình AI dưới dạng ONNX để inference nhanh |
| AJAX / jQuery                    | Gọi API bất đồng bộ, không cần reload trang             |
